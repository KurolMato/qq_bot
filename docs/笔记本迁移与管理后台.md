# 笔记本迁移与管理后台

> 项目根目录现在只保留 `机器人管理.cmd` 作为日常入口。安装、启动、停止和平台登录都从
> 管理器菜单选择；对应内部脚本统一存放在 `scripts\windows`。

本说明适用于：把旧电脑 `E:\video_analysis` 中的项目复制到只有 `C:` 盘的笔记本，并在笔记本本地运行。

推荐使用下面两个简单路径：

```text
C:\video_analysis
C:\NapCat.Shell
```

不建议放进桌面、OneDrive 或很深的中文目录，以免同步、权限和命令行转义引起问题。

项目会为每台电脑使用独立的 Python 环境：

```text
.venvs\电脑名称
```

排行榜、平台登记、昵称、图片缓存和密钥会随项目复制到笔记本。笔记本会创建自己的 Python 环境，不会使用旧电脑的 `.venv`。

## 一、旧电脑上准备迁移文件

在旧电脑上双击：

```text
E:\video_analysis\机器人管理.cmd
```

在菜单中选择“完全关闭机器人”，确认机器人、下载服务和 NapCat 已退出。

确认机器人、下载服务和 NapCat 已退出。因为项目已经在移动固态硬盘 `E:` 上，先把旧电脑 `D:` 盘里的 NapCat 也暂存到移动硬盘：

```text
D:\NapCat.Shell  ->  E:\NapCat.Shell
```

安全弹出移动硬盘并插到笔记本，然后在文件资源管理器中复制：

```text
移动硬盘:\video_analysis  ->  C:\video_analysis
移动硬盘:\NapCat.Shell   ->  C:\NapCat.Shell
```

移动硬盘在笔记本上不一定仍是 `E:`，按文件夹名称找到即可。NapCat 必须复制整个目录，只复制 `launcher-win10.bat` 无法运行。

项目中的 `.env`、`data`、`secrets`、`assets\instruction.png` 和昵称文件必须保留。`.venv`、`.venvs`、`downloads`、`.pytest_cache` 和 `__pycache__` 可以不复制；如果已经全部复制也没关系。

## 二、笔记本从零安装

### 1. 确认项目位置

复制完成后应能看到：

```text
C:\video_analysis\机器人管理.cmd
C:\NapCat.Shell\launcher-win10.bat
```

### 2. 一键安装 Python、Node.js 和 FFmpeg

双击项目目录中的 `机器人管理.cmd`，选择 `6`。

这个脚本使用 Windows 自带的 `winget` 安装：

- Python 3.12 x64
- Node.js LTS
- FFmpeg

Windows 弹出权限确认时选择“是”。安装完成后关闭窗口；如果后续仍提示找不到命令，重启一次 Windows。

如果提示找不到 `winget`，打开 Microsoft Store，安装或更新“应用安装程序（App Installer）”，然后重试。

也可以在 PowerShell 中逐条手动执行：

```powershell
winget install --id Python.Python.3.12 -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Gyan.FFmpeg -e
```

安装后新开一个 PowerShell，验证：

```powershell
py -3.12 --version
node --version
npm --version
ffmpeg -version
```

四条命令都能显示版本号才算完成。

### 3. 安装 QQ 和 NapCat

NapCat 必须和电脑上的 QQ 版本及 `x64` 架构匹配，否则会出现 `PacketBackend 不支持当前QQ版本架构`。

推荐迁移方式：

1. 在笔记本安装与该 NapCat 版本兼容的 Windows x64 QQ。
2. 确认旧电脑的整个 `D:\NapCat.Shell` 已复制为 `C:\NapCat.Shell`。
3. 运行 `C:\NapCat.Shell\launcher-win10.bat 机器人QQ号`，完成 QQ 登录。
4. 在本项目管理后台把 NapCat 启动脚本改成 `C:\NapCat.Shell\launcher-win10.bat`。

如果不复制旧 NapCat，则在笔记本重新安装 NapCat，并在管理后台填写新的 `launcher-win10.bat` 完整路径。首次启动可能需要扫码或设备验证。

### 4. 安装 nxapi

完成上面的基础软件安装后，`setup-laptop.cmd` 会检查 nxapi，并询问是否自动安装。也可以手动执行：

```powershell
npm install --global nxapi@next
```

验证命令：

```powershell
nxapi --version
```

nxapi 安装完成不代表观察账号已经登录；Switch 登录需要在后续通过 `机器人管理.cmd` 的选项 `7` 完成。

## 三、一键配置项目环境

进入项目目录，双击 `机器人管理.cmd`，选择 `5`。

它会完成这些工作：

1. 检查 Python 3.12、Node.js 和 FFmpeg。
2. 根据当前 Windows 电脑名称，在 `.venvs` 中创建这台电脑专用的 Python 环境。
3. 安装这台电脑需要的 Python 依赖，并为抖音图文创建独立的 `f2-电脑名称` 环境，不修改另一台电脑的运行环境。
4. 检查 nxapi；未安装时可按提示安装。
5. 创建缺少的配置目录，将 `secrets` 权限限制为当前用户、SYSTEM 和管理员，并打开本地管理后台。

笔记本只需要打开一次 `机器人管理.cmd` 并选择 `5`。项目即使包含旧电脑的虚拟环境，启动脚本也会根据笔记本电脑名称选择新的环境。

## 四、使用本地管理后台

以后双击 `机器人管理.cmd`，选择 `3` 打开管理后台。

管理页会在浏览器打开。它只监听本机地址，并用项目中自动生成的随机令牌登录，不对局域网或公网开放。

管理页可以：

- 查看 NapCat、视频服务、QQ Bot 和 OneBot WebSocket 状态。
- 查看 Python、FFmpeg、Node、nxapi、yutto、yt-dlp 是否齐全。
- 设置启用群号、NapCat 启动脚本、机器人 QQ、视频上限、各平台轮询间隔，以及游戏发售提醒时间。
- 写入 Steam Web API Key、SteamGridDB Key 和 PSN NPSSO。页面只显示是否已配置，不回显密钥。
- 打开 Switch/PSN 登录窗口，或单独重启 QQ Bot。
- 在“游戏发售日历管理”中新增或编辑游戏名、平台、发售日期和本地封面；上传图片后可拖动、缩放选区，自由决定最终横版封面的取景。

保存普通配置后，重启机器人使配置生效。密钥文件保存在 `secrets` 目录，不要把这个目录发给别人。若项目是手动复制且未重新运行安装脚本，可右键用 PowerShell 运行 `tools\harden_secrets.ps1` 修复该目录的访问权限。
游戏日历的表单保存后立即生效，不需要重启；数据和上传图片分别保存在
`data\game-calendar.db` 与 `data\game-calendar-images`，迁移电脑时应一起复制。
发售日提醒默认在 09:00 后向允许群发送“明日发售”和“今日发售”卡片；提醒配置保存后需重启 QQ Bot 生效，已发送记录也保存在 `data\game-calendar.db`。

抖音图文转 MP4 必须在“抖音 Cookie 文件”中填写 Netscape 格式 Cookie 文件的完整路径，例如
`C:\video_analysis\secrets\douyin-cookies.txt`。普通抖音视频仍可使用该文件，也可以单独使用浏览器 Cookie 配置。

## 五、迁移后需要重新处理的登录

完整复制项目后，以下数据会一起带到笔记本：

- `.env` 中的项目配置
- `data` 中的登记、昵称、状态和排行榜数据
- `secrets` 中的 Steam、SteamGridDB、PSN 密钥
- 项目中的图片和缓存

Xbox 令牌可以随项目迁移；机器人使用跨进程锁刷新并立即写回 `secrets\xbox-tokens.json`。不要在两台电脑上同时运行同一份观察账号令牌。

以下内容通常绑定 Windows 用户目录，换电脑后要重新登录：

### Switch / nxapi

双击 `机器人管理.cmd`，选择 `7`。

按窗口提示用新的回调链接完成登录。nxapi 登录保存在 Windows 用户目录中，不在项目文件夹里，因此笔记本必须重新登录一次。

### NapCat / QQ

在笔记本上重新登录机器人 QQ，并在 NapCat 中设置 OneBot 11 反向 WebSocket：

```text
ws://127.0.0.1:8081/onebot/v11/ws
```

然后在管理后台把“NapCat 启动脚本”改为笔记本上实际的 `launcher-win10.bat` 路径。

### PSN 和 Steam

管理后台显示“已配置”时一般不用重新填写。若接口提示登录失效，可直接在管理后台覆盖写入新的 NPSSO 或 API Key。

## 六、正式启动和检查

双击 `机器人管理.cmd`，选择 `1`。

等待 NapCat 登录后，在管理后台确认四项状态正常，再在群里测试：

```text
/switch status
/switch list
/psn list
/steam list
```

## 七、笔记本长期运行设置

为了避免机器人莫名离线，建议：

- 接通电源时将“睡眠”设为“从不”。
- 把“合上盖子时”设置为“不采取任何操作”。
- 允许 QQ、NapCat 和 Python 通过 Windows 防火墙的专用网络规则。
- 不要同时在旧电脑和笔记本运行同一个机器人 QQ。
- 以后新产生的数据只在笔记本 `C:\video_analysis` 中；若要切回旧电脑，需要复制最新的 `.env`、`data` 和 `secrets`。
- 保持笔记本散热，并定期重启 QQ、NapCat 和机器人。

## 八、日常快捷入口

| 文件 | 用途 |
| --- | --- |
| `机器人管理.cmd` | 根目录唯一入口，包含以下全部功能 |
| `scripts\windows\start-all.cmd` | 启动整套服务和 NapCat |
| `scripts\windows\stop-all.cmd` | 关闭整套服务和 NapCat |
| `scripts\windows\open-admin.cmd` | 打开本地管理后台 |
| `scripts\windows\restart-qq-bot.cmd` | 只重启 QQ Bot |
| `scripts\windows\setup-laptop.cmd` | 新电脑首次安装依赖 |
| `scripts\windows\install-laptop-prerequisites.cmd` | 安装 Python、Node.js 和 FFmpeg |
| `scripts\windows\switch-login.cmd` | 重新登录 Switch 观察账号 |

# 引用消息

私聊可以引用文字、图片或图文消息再提问。群聊中引用消息后 @机器人并提问，也会把引用原文和图片交给助手；例如“你怎么看”“比较一下”。群范围、私聊白名单和启用开关保持原有规则。

引用机器人自己发送的视频时保持静默，包括 QQ 引用时自动带上的 @；这类视频评论不会触发群问答或排行榜等图片功能。引用其他人的视频、机器人的文字或图片仍按原有规则处理。

当前消息图片与引用图片一起发送，按“当前图片在前、引用图片在后”标明来源。合计最多 `QQ_DSH_MAX_IMAGES` 张，且不超过 4 张；超过时提示分开发送，不静默丢图。图片下载失败或引用消息不可用时会简短提示重新发送，不发送缺失上下文的问题。

优先使用 QQ 适配器已解析的引用内容；缺失时通过 `get_msg` 获取。支持消息段数组和 CQ 字符串。引用文字超过 3000 字时截断并明确标记，只读取直接引用的那条消息，不递归拉取整条引用链。语音、视频等附件内容不在本次接入范围内。

不会发送“已收到”或排队提示。排行榜直接调用功能仍按当前请求执行，引用原文不会被当成新的命令自动执行。

重启 QQ 机器人后生效，无新增依赖。本次功能运行需更新 `qq_bot/dsh_commands.py` 和 `qq_bot/group_dsh.py`，使用现有客户端与图片处理模块；不需要复制或改动运行数据库。

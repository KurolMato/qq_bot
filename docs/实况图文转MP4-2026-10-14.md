# 抖音、小红书实况图文转 MP4

本机代码已完成。含实况照片的作品按原顺序合并为一个 MP4，实况保留动态片段和片段自带声音，混排的普通图片停留 3 秒。只有静态图片的作品继续发送图片，普通视频继续原来的视频下载流程。

输出统一为 H.264、yuv420p、30 fps 和 AAC 48 kHz 双声道，使用 faststart。按首张素材方向选择 720×1280 或 1280×720，等比缩放并补黑边，不裁切。作品提供动态标识但没有可用动态地址时明确失败，不以静态封面冒充实况。下载候选地址可轮换；转换共用时间预算。

抖音兼容详情和 f2 备用解析均保留每张图片的动态地址及顺序，`/video/` 形式的图文链接也可在兼容详情中识别。小红书从网页状态的图片列表提取实况视频流，兼容桌面/移动页面及备用流，保留分享参数。纯静态小红书图文也接入图片发送流程。

新增路径不向素材 CDN 携带站点 Cookie；小红书 CDN 请求每次重定向前检查目标域名。用户 `.env`、原始 Cookie、数据库和虚拟环境未修改。

## 验证

本机使用 `tools/select_python.cmd` 对应环境。最终 143 项针对性测试与 API、存储模型、客户端、群发送回归测试通过，包含分享参数保留和媒体下载凭据隔离验证。平台接口使用模拟数据，不向真实群发消息。

实际调用本机 FFmpeg，以本地生成的 HEVC/MOV（带声音）、H.264（静音）及 PNG 混排进行验证：输出编码、像素格式、帧率、尺寸、时长和 faststart 正常；动态片段不同时间的画面哈希不同，输出音频采样非静音。随后已对下述小红书真实分享链接做本机转换验证，但未验证 QQ 群实际播放；平台 403、风控、已删除作品或缺失媒体地址仍可能失败。

## 09:45 小红书短链失败补充修复

故障链接 `https://xhslink.cn/o/8yab3Ulqx46` 的桌面请求依次跳转到具体笔记、登录页。旧解析只看最终 URL，没有从跳转历史及登录页的 `redirectPath` 恢复笔记地址。相同链接使用手机 User-Agent 能到达笔记页面。

现在优先使用手机请求，必要时再试桌面请求；从可信域名的跳转历史和登录页目标地址恢复笔记，保留完整分享参数。对于未提供笔记地址的登录页，返回明确的登录提示。该笔记的实际类型是普通视频，备用页面解析会提取其视频流，不把封面当成图片发送。

本次 114 项短链、下载与实况相关测试通过。对原始故障链接只在本机临时目录进行转换，成功生成 1,100,241 字节、7.321333 秒、720×1280 的 H.264/yuv420p + AAC MP4：`.tmp/xhs-convert-verify-293f275c/live-photo.mp4`。没有向群发送验证消息，没有修改原始 Cookie 或运行数据库。

本次补充修复的全部运行文件为 `app/downloader.py`、`app/live_photo.py`；新增验证文件为 `tests/test_xiaohongshu_share.py`。其他实况功能运行文件仍按前文清单同步。本机代码已修复，需要再次重启视频 API 才加载此修复；本次未重启、未提交、未推送或更新笔记本。

## 09:47 抖音短链 SSL 中断补充修复

故障链接 `https://v.douyin.com/jqT-BdpUyM0/` 在普通下载器的短链网页请求阶段出现 `SSL: UNEXPECTED_EOF_WHILE_READING`。旧短链解析在网络错误后直接返回原短链，而下载器只在 403/新 Cookie 提示时进入兼容解析，SSL 中断没有恢复路径。

只读复查确认首个 302 响应即可取得作品编号 `7695582229237452083`。现在从首个可信跳转中恢复规范作品地址，不再为了取得编号继续连接分享网页；短链最多尝试 3 次、共享最长 30 秒的解析预算，并限制重定向次数。SSL EOF、连接重置和超时也触发一次兼容详情/媒体重试，下载重试共用下载时间预算。持续失败会返回明确的连接中断提示。不关闭 TLS 证书验证。

本次 123 项短链、下载和双平台实况相关测试通过。原始故障链接在本机临时目录成功转换为 1,824,596 字节、11.4 秒、576×1024 的 H.264/yuv420p + AAC MP4：`.tmp/douyin-short-verify-3fa747a7/douyin.mp4`。验证前后原始 Cookie 文件 SHA-256 相同，没有向群发送验证消息。

本次补充的全部运行变更文件为 `app/downloader.py`；验证文件为 `tests/test_douyin_transport.py`（新增）和 `tests/test_downloader.py`。同步笔记本时其他实况功能文件仍按前文清单一起更新。需重启视频 API 加载本次及前述小红书修复；本次未重启、未提交、未推送或更新笔记本。

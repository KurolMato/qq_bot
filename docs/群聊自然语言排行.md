# 群聊自然语言排行

在允许的群里 @机器人，可以直接请求现有排行榜图片：

支持短词：`@机器人 排行` 或 `@机器人 rank` 直接发送 `/rank`；`周榜`、`月榜`、`我的排名` 也可以直接用。其他项目图片见 [项目图片短词调用](项目图片短词调用.md)。

| 示例 | 对应功能 |
| --- | --- |
| 能不能把今天的排行榜发一下？ | `/rank` |
| 发一下昨天的排行榜 | `/rank y` |
| 看看本周排行榜 | `/rank w` |
| 来一张月榜 | `/rank m` |
| 发一下我的排名 | `/rank me` |
| 看看我的今日排行 | `/rank me d` |

没有问号也可以。个人排行沿用 `/绑定` 的账号关联；无数据时沿用命令的提示。

需要启用 `QQ_DSH_GROUP_ENABLED`（默认 true）。群范围沿用 `QQ_DSH_GROUPS`（未配置时使用 `QQ_ALLOWED_GROUPS`），同时保留排行榜命令自己的群权限检查。

明确的排行请求直接调用本地排行榜功能，不需要等待模型回答，也不要求启用私聊 DSH。没有 @机器人、禁用群聊或不在允许范围的消息不会触发。请求会在本群上一项问答或排行完成后处理，等待时不发确认或排队提示，完成后直接发送排行榜。

“排行榜怎么发”等用法问题仍走群问答。否定请求、多个时间范围、上周/上月等未接入表达不自动转换成今日榜，可使用原有明确命令。指定月份支持“9月排行”和“我的9月档案”。

更新后重启 QQ 机器人，无新增依赖。同步其他电脑的文件清单见 [项目图片短词调用](项目图片短词调用.md)，无需复制运行数据库。

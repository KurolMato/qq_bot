# QQ 私聊操作浏览器

通过微软的 [Playwright MCP](https://github.com/microsoft/playwright-mcp) 为 QQ Bot 提供网页操作工具：打开 B 站、搜索视频、点击播放/暂停、切换页面和查看网页状态。当前接入的是浏览器操作，不包含其他 Windows 软件的桌面点击，也不自动理解整段视频内容。

## 安装与启用

1. 本机需安装 Node.js 18+ 和 Microsoft Edge。
2. 运行 `scripts/windows/setup-computer-use.cmd`。脚本将固定版本 `@playwright/mcp@0.0.83` 安装到 `.tools/<COMPUTERNAME>/playwright/`，不会向机器人 Python 环境添加依赖，也不下载额外 Chromium。
3. 确认 `QQ_DSH_ENABLED=true`、`QQ_DSH_USERS` 包含自己的 QQ 号，`QQ_DSH_PERMISSION_MODE=workspace-write`。`QQ_DSH_BROWSER_ENABLED` 默认为 `true`，设为 `false` 可停用。
4. 重启 QQ Bot，私聊发送 `/dsh status`。显示“浏览器插件：已配置”表示启动配置已找到插件；实际工具会在 DSH 下次启动时加载。如果当前进程尚未加载 `/dsh restart`，先在 `机器人管理.cmd` 中手动选择“只重启 QQ Bot”。

私聊自然语言示例：

- “打开 B 站，搜索黑神话悟空实机演示。”
- “播放搜索结果里的第一个视频。”
- “暂停刚才那个视频。”
- “把播放进度跳到两分钟，确认一下是否正在播放。”
- “上网搜两张橘猫图片发给我。”

这些是给 AI 的操作请求，不是新增的固定 QQ 命令。模型需要调用实际浏览器工具，不能仅凭回复文字判断操作已完成。登录、会员限制和验证码可能需要本人在打开的浏览器中处理。

搜图时模型可使用现有联网搜索或浏览器提取图片直链，机器人再下载并作为普通 QQ 图片发送，先文字后图片，每轮最多 3 张、单张最多 8 MB。不会保存到表情库；下载或 QQ 发送失败会提示，超时或取消的回复不执行发图。网站限制下载时可让它换个来源。实现与同步文件见 [DSH私聊助手.md](DSH私聊助手.md) 的“能搜图发图”。

## 浏览器资料与生命周期

插件使用一个可见的独立 Edge 浏览器，资料存放在 `.tools/<COMPUTERNAME>/browser-profile/`，截图等输出在相邻的 `browser-output/`。首次访问 B 站需要时自行登录，后续会保留该独立资料目录中的登录状态；不读取或覆盖平时 Edge 的个人资料。

每个主人 DSH 进程只启动一个 MCP 工作进程，各个私聊会话复用它，避免多个浏览器同时争用同一个资料目录。`/dsh new` 只更换对话，浏览器工具仍可继续使用；停止或重启 DSH 时浏览器连接可能关闭，下次操作会重新打开。

浏览器 MCP 通过本地 stdio 连接，不开放远程控制端口。群聊、主动消息、风格总结、自动诊断和手工只读自检不会挂载该插件。浏览器操作与 DSH 文件沙箱是不同能力，只有白名单私聊使用该工具。

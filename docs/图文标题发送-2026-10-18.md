# 小黑盒与 B 站图文标题

两平台图文在图片前附上作品标题，以普通文本显示：

- 图片不超过 5 张：标题文字和图片在同一条群消息中，文字在前。
- 图片超过 5 张：合并聊天记录的首个节点为标题文字，其余节点依次放图片。
- 标题不计入图片数量；没有标题或使用缺少标题字段的旧版 API 时，按原规则只发图片。
- 标题中的 CQ 字样按普通文本发送。只发送标题，不自动追加整段正文。其他平台和视频消息没有新增标题发送行为。

## 数据传递

小黑盒从帖子 `title` 读取；B 站从正文标题模块、基本信息或动态 opus 标题读取，旧专栏支持标题标签与网页标题元信息，正文小标题不会覆盖作品标题。

下载器在有序图片列表上附带标题，保持旧列表返回格式兼容。API 在任务中保留并返回 `title`，客户端传给群发送逻辑。任务仅在内存保存，不改数据库结构。
